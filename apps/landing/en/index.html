Three steps to production

From an empty server to a live app, no Kubernetes and no root key.

Add a server
A 15-minute token. The agent enrolls and opens its outbound connection.
shipkeep server add
Push your code
Build, migrate, health check, switch. The old release serves until the end.
git push origin main
Observe
Logs, metrics and alerts for 30 days, nothing to assemble.
shipkeep status

FrequentlyAsked questions

Is Shipkeep really free?
Yes. Apache-2.0, no proprietary edition. A hosted version will come as an option.
Do I need Kubernetes?
No. Shipkeep places, monitors and fails over your Docker containers across servers.
What if the control plane goes down?
Your apps keep running. Each agent keeps its routing table and reconnects by itself.
Where do my secrets go?
Encrypted in PostgreSQL and sent only to the agent that needs them. The repo only holds their names.
Which servers are supported?
Any Linux server with systemd. The installer adds Docker, Caddy and WireGuard if needed.
